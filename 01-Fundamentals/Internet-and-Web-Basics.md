# Internet and Web Basics

## Definition

The Internet is a global network that connects millions of devices, allowing them to exchange information using standard communication protocols such as TCP/IP.

---

## Client

A client is a device or application that requests services from a server.

Examples:

- Web Browser
- Flutter Application
- Mobile App
- Postman

---

## Server

A server is a computer or application that provides services or resources to clients.

Examples:

- Apache
- Nginx
- PHP
- Node.js

---

## Client–Server Communication

```text
Client
   │
HTTP Request
   │
Server
   │
HTTP Response
   │
Client
```

---

## Why It Matters in Cyber Security

Understanding the client-server model is essential because most web attacks occur during HTTP communication between clients and servers.

Examples:

- SQL Injection
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Server-Side Request Forgery (SSRF)

---

## Summary

- The Internet connects devices worldwide.
- Websites are hosted on servers.
- Browsers act as clients.
- Clients communicate with servers through HTTP requests and responses.
- Understanding this communication is fundamental to Web Application Security.
